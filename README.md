# Windows Server Automation Lab

This repository contains hands-on Windows Server, Microsoft 365, and automation projects developed to improve operational efficiency, service reliability, identity management, and infrastructure administration.

The projects focus on real-world administrative tasks commonly performed by Systems Administrators, Infrastructure Engineers, Microsoft 365 Administrators, and IT Operations teams.
